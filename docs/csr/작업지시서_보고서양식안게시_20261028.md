## 2. 절대 준수 사항

1. `main` 에 직접 커밋·push 금지. 브랜치 `feat/report-design-2026-10` 에서 작업하고 PR을 만든다. push·merge·deploy는 🧑 체크포인트에서 사람이 실행한다.
2. 운영 서버 `asm.ascendotyre.com` 과 Neon DB(`db/*.sql`)는 손대지 않는다. 이번 작업은 **정적 파일 + 프런트 화면 추가**뿐이다.
3. 기존 화면(목록·상세·대시보드·관리·흐름도·핵심문서·표준양식)의 코드·동작을 바꾸지 않는다. `navigation.js` 는 항목 1개 추가만.
4. 게시 HTML(`report-design.html`)의 **본문 데이터·문구는 수정하지 않는다.** 허용 범위는 §4-3의 임베드 보조 스크립트 추가뿐이다. 내용 수정 요청은 발주자에게 돌려보낸다(원본은 Drive 폴더에서 재생성).
5. 파일명은 ASCII로 둔다(`public/csr/reports/report-design.html`, `xlsx/*.xlsx`). URL 인코딩 문제 회피(핵심문서 `DOC-xx.pdf` 선례). 내려받기 표시명만 원본 한글 이름을 쓴다.
6. 초기 청크 500 KB 한도를 넘기지 않는다. HTML은 `public/` 정적 자산 + iframe 이므로 번들에 들어가지 않는다. 새 화면은 동적 import.
7. 🧑 사람 체크포인트는 **사이트·계정 → 클릭 경로 한 줄씩 → 입력값 → 완료 화면 모습** 을 반드시 적는다(아래 §6, §8).
8. 커밋 메시지는 영문 prefix + 한국어 요약: `feat(csr): report design page (/csr/reports)` 형식. 한 단계 = 한 커밋.
9. 모르는 값(저장소 로컬 경로, 아이콘 이름 등)은 추측하지 말고 §9 「결정 대기」에 적고 멈춘다.

### 4-3. HTML 임베드 보조 스크립트 (D1 보완, 본문 불변)
`report-design.html` 의 `</body>` 직전에 **아래 블록만** 추가한다(다른 줄 수정 금지).
```html
<script>
(function(){
  // CSR 사이트(부모)가 보내는 언어를 따른다. 단독으로 열면 자체 토글이 그대로 동작.
  var q = new URLSearchParams(location.search);
  function apply(l){ var b=document.querySelector('.lang button[data-l="'+(l==='id'?'id':'ko')+'"]'); if(b) b.click(); }
  if (q.get('lang')) apply(q.get('lang'));
  if (q.get('embed')==='1') { var n=document.querySelector('.lang'); if(n) n.style.display='none'; }
  window.addEventListener('message', function(e){ if(e.data && e.data.type==='asm-lang') apply(e.data.lang); });
  // 부모에 높이를 알려 iframe 스크롤 이중화를 막는다.
  function post(){ try{ parent.postMessage({type:'asm-report-height', h: document.documentElement.scrollHeight}, '*'); }catch(_){} }
  new MutationObserver(post).observe(document.body,{subtree:true,attributes:true,childList:true}); window.addEventListener('load', post);
})();
</script>
```
확인: 단독으로 `report-design.html?lang=id&embed=1` 을 열면 인니어로 뜨고 토글이 숨는다.
커밋: `feat(csr): embed hooks for report design html`
